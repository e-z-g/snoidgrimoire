# SnoidGrimoire

Browser tools for exploring the files of Brøderbund's logic game *The Logical
Journey of the Zoombinis* (1996). It is a sibling of
[grimoire](https://github.com/ratlizard/grimoire). That site does the same for
*Cythera*.

`index.html` starts on the game's map of the journey. Each of the sixteen
places opens into its scene as you zoom in. The scene shows its route and its
help at each level. Zoombiniville can be viewed all the way around on a screen
or in a VR headset. It has its houses, reward buildings, inhabitants, clock,
and music. There is also an archive browser for every picture, sprite sheet,
sound, tune, palette, cursor, string, walk, and animation script in the game's
Mohawk archives. Both work with a copy you supply or with the Internet
Archive's copy.

The site is at <https://e-z-g.github.io/snoidgrimoire/>. It also works from
a local folder with no build step.
