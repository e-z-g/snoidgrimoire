# SnoidGrimoire

Browser-based tools to explore the files of *The Logical Journey of the
Zoombinis* (1996), the logic game by Brøderbund. A sibling of
[grimoire](https://github.com/ratlizard/grimoire), which does the same for
*Cythera*.

`index.html` opens on the journey's map, the game's own, where each of the
sixteen places opens into its scene as you zoom in, with its route and its
help at each level. Zoombiniville can be stood in, all round, on a screen
or in a VR headset, with its houses, reward buildings, inhabitants, clock
and music. Beside them is an archive browser: every picture, sprite
sheet, sound, tune, palette, cursor, string, walk and animation script in
the game's Mohawk archives. Both read a copy you supply or the Internet
Archive's.
It is at <https://e-z-g.github.io/snoidgrimoire/>; it also opens from a
folder, and there is no build step.
